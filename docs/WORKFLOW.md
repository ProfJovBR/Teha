# Fluxo de colaboração

1. Cada desenvolvedor usa sua própria conta e seu Codex, trabalhando na branch atribuída (`frontend` ou `backend`).
2. Sempre atualizar a branch local antes de trabalhar e evitar edições simultâneas dos mesmos arquivos.
3. Alinhar contratos entre frontend e backend antes de implementar integrações.
4. Abrir Pull Request da branch de trabalho para `main`; revisar diferenças e testes antes do merge.
5. Após o merge, sincronizar ambas as branches com `main` para reduzir conflitos.
6. Não compartilhar tokens, segredos ou dados clínicos em commits, issues ou mensagens de PR.

Para tarefas independentes e paralelas, criar branches temporárias derivadas da branch da equipe, em vez de dois Codex escreverem no mesmo diretório ou branch ao mesmo tempo.
